# Naming Convention

All Azure resources follow the format:

```
<resource>-<purpose>-<environment>-<region>-<instance>
```

Examples

| Resource | Example |
|----------|---------|
| Resource Group | rg-platform-prod-aue-001 |
| VNet | vnet-hub-prod-aue-001 |
| Firewall | afw-hub-prod-aue-001 |
| Key Vault | kv-platform-prod-aue-001 |
| Log Analytics | law-platform-prod-aue-001 |
| Bastion | bas-hub-prod-aue-001 |
